NoteStar - What's new
=====================

0.3.0
-----
- Better search. In every note (Ctrl+Shift+F): all matching lines of
  each note with line numbers, the words highlighted, match case and
  whole word options, keyboard navigation; the selected words are
  searched right away. In the open note (Ctrl+F): every match is
  highlighted in the editor and in the preview, the current one stands
  out, with the same options, and a button (Ctrl+Enter) searches all
  notes for the same words.
- Drop .md / .txt files (or whole folders) from Explorer / Finder into
  NoteStar: they are copied into the notes folder (onto a folder in the
  tree, or next to the open note) with their subfolders and opened.
- AI token counter in the status bar: the tokens used by the AI
  features (input, output, prompt cache), counted from every answer of
  the Claude API, DeepSeek and the Claude Code CLI. Click it for the
  details per provider and model, this session and all time (with the
  cost the Claude Code CLI reports), and to reset the counter. The
  counts are kept across restarts.

0.2.0
-----
- Full Markdown (CommonMark + GitHub extensions: tables, task lists,
  nested lists, strikethrough, autolinks, footnotes, ==highlight==,
  heading links, safe inline HTML) in the preview and in AI answers.
- Formatting toolbar with keyboard shortcuts (Ctrl+B, Ctrl+I, Ctrl+K,
  Ctrl+1..3, Ctrl+Shift+7/8/9 ...) and a Markdown cheat sheet.
- Images: insert from a file, paste (Ctrl+V) or drop into the editor.
  They are saved in an "attachments" folder next to the note and synced
  along with the notes. Set the size with ![text|300](...) or
  ![text](... =300x), or click the picture in the preview.
- Pictures show up in the notes tree: click to view, drag into the
  editor or insert them from the context menu.
- Closing a tab asks first (x button, middle click, Ctrl+W).
- Fix: in English the notes tree header and the editor hint were still
  in Hungarian.

0.1.0
-----
- First version: plain text / Markdown notes in a folder, editor with
  live preview, notes tree, full-text search.
- Two-way sync with any folder (OneDrive / Dropbox / Google Drive /
  iCloud desktop folders are detected), OneDrive (own App ID),
  Dropbox (own App key) and WebDAV. Conflict copies instead of lost
  edits, mass-delete guard, recycle bin for local deletions.
- Optional AI (off by default): summary, corrections, rewriting,
  translation, task lists, merging sync conflicts.
- GitStar themes, Hungarian / English UI, self-update.
